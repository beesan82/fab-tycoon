# 初期ライン一直線化ログ（trackLINE）

- 日付: 2026-11-11〜11-12
- 作業場所: 隔離クローン `~/workspace/projects/fab-tycoon-trackLINE`（本線 1.0.0 (21) = ae94156 相当のコピー）。本線・他クローンは無変更。push なし。
- 起点: ユーザーの実機フィードバック「輪っかにしないで」「一直線がいい」。蛇行でも見た目が循環路に読めることが不満の核。目的はトポロジーの完全直線化ではなく「輪っか・蛇行に読めないこと」。初期ラインが組まれていること（装置11台＋ロットのプリシード）は維持。

## 1. 方式選定

### ルート分析（28nm・72ステップ、実測・コード精査）
- 工程別回数: 成膜20・露光15・エッチ20・注入8・CMP5・検査3・PKG1。
- 主な遷移: 成膜→露光×15、露光→エッチ×15、エッチ→注入×8、注入→成膜×7、エッチ→成膜×6、エッチ→CMP×5、成膜→エッチ×5、CMP→成膜×4、検査→成膜×2。成膜への帰還が計19回と多い（再入構造）。
- 搬送モデル: 一方向・1セル1ロットの有向循環路上の BFS 最短経路。到着時は空きポートへ入線、処理済みポートがある場合のみドライブスルー、全ポート使用中なら最終セルでその場待ち。レール到着時のストッカー退避は現行設計に無い（過去に迂回交通が環を塞いだため撤回済み）。ストッカー行きは出発時選択のみ。

### 方式A（一直線＋再入回数分の駅複製でワンパス）— 不成立
1. 循環が無いと層境界ペア（注入→成膜など上流へ戻る遷移）が到達不能になり凍結する。
2. 初期装備11台では再入回数（成膜・露光・エッチ各12回以上）に複製が足りない。単一台工程（注入・CMP・検査）は複製自体が不可能。
3. 直線1レーン両岸に全駅を工程順単調配置すると幅合計28セル > フロア幅16で収まらない。

### 方式B（本線一直線＋戻りはフロア端の1レーンに分離、循環トポロジー維持）— 採用
- 本線（装置が並ぶ主役のライン）は画面中央の水平一直線1本。ロットの戻りはフロア外周の南端・東端・西端の細い1レーンに分離した。
- **正直な評価**: トポロジーは循環のまま（搬送モデルの前提上、循環を断つと凍結する）。「一直線」なのは装置が並ぶ本線の見た目であり、戻りレーンはフロアの縁に寄せた従レーンとして読まれる配置にした。画面の大半（北〜中央）は一直線のラインと装置列だけが見える。

## 3. 最終レイアウト（S9c、Layout.swift 実装済み）

```
y=2:            [L1 r90]  [L1 r90]              ← 北岸・奥（露光）
y=4: [入] [D1] [D1]    [C1] [Q1]    [出]        ← 北岸（成膜→露光→CMP→検査の順）
y=6: ●━━━━━━━━━━━━━━━●  ← 本線（一直線・東向き16セル）
y=7: [P1] [St] [E1][E1][E1] [I1]  ↓            ← 南岸（PKG／ストッカー／エッチ／注入）
     ↑                        ↓
y=15:●━━━━━━━━━━━━━━━●  ← 戻りレーン（西向き）
     （西柱 y=7..14 北向き／東柱 y=7..14 南向き）
```

- レール48セル: 本線 y=6 が16セル（(0,6) corner・東、x=1...14 straight・東、(15,6) corner・南）＋戻り32セル（東柱 (15,7)...(15,14) 南、(15,15) corner・西、底辺 x=14...1 (y=15) 西、(0,15) corner・北、西柱 (0,14)...(0,7) 北）。
- 施設: 投入口 entry (0,4)（ポート (0,6)）、出荷 shipping (15,4)（ポート (15,6)）、ストッカー (3,7)（ポート (3,6),(4,6) — 本線に直接面し、全成膜ポートから退避距離≤3）。
- 装置11台: 北岸 D1 (1,4)・D1 (3,4)・L1 (5,2) r90・L1 (8,2) r90・C1 (11,4)・Q1 (13,4)（西→東に工程順）。南岸 P1 (1,7)・E1 (5,7)・E1 (7,7)・E1 (9,7)・I1 (11,7)。L1 は 3幅×4奥行のため回転 r90 で配置（slots を回転対応に拡張）。
- レーン位置は `LayoutTemplate.templateLaneY = 6` として定数化。
